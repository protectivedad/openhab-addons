Authorize openHAB binding for Honeywell

On this page you can authorize your openHAB Honeywell Bridge configured with the consumerId and consumerSecret of the Honeywell Application on your Developer account, you have to login to your Honeywell Account and authorize this binding to access your account.

To use this binding the following requirements apply:

  • A thermostat registered on the "Resideo Smart Home" system
  • A Honeywell Developer account.
  • Register openHAB as an App in the Honeywell Developer "MY APPS" page.

You have already installed the binding because you are here. At this point there maybe no "Connect to Honeywell: {Bridge Name}" because you haven't setup any bridges and that is okay. Continue with the steps below and after creating the bridges refresh this page.

Create Honeywell Application

Follow the instructions in the FAQ at Where do I start?

  • Sign up for an account
  • Create an API key

There are only two items in the Honeywell App page App Name and Callback URL. The app name can be anything you like and isn't important. The Callback URL needs to be the same as the one shown on this page. I suggest copying the URL to clipboard and using that to fill in the Honeywell website.

Callback URL: ${redirectUri}

Now you can select the new app name and copy the Consumer Key and Consumer Secret entries. Go to openHAB and create a Honeywell Bridge. Entering the Consumer Key and Consumer Secret in the appropriate fields. Save the bridge. It should fail and be in an "OFFLINE" mode. This is expected. Now refresh this page.

If everything went well there should be a button for each bridge you created with the words "Authorize Bridge". You only need one bridge for all the devices but it will list all available if you created more than one.
